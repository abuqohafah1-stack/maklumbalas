# Maklum Balas · Sofwah Arabic Grill

Borang maklum balas pelanggan untuk QR di meja setiap cawangan Sofwah Arabic Grill.

- Pautan cawangan: `https://maklumbalas.sofwah.my/?cawangan=<cawangan>`
  (gurun, kuala-nerang, sungai-petani, alor-setar, aman-central, jitra)
- Jawapan dihantar ke Web App Google Apps Script "Sofwah Feedback" dan disimpan dalam Google Sheet HQ.
- Repo ini awam: jangan letak PIN, kata laluan atau data pelanggan di sini.
